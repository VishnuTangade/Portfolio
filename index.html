DevPilot

Tech Solutions Inc. | Backend Development

Project Duration 1 Months (mar 2025 - Apr 2025)
Technologies Used Java, Spring Boot, Spring Security, Next.js, React, PostgreSQL, PGVector, Spring AI, OpenAI, GitHub OAuth, Docker

About my Project

    DEV PILOT - AI-Powered Codebase Assistant
    Developed a full-stack AI-powered codebase assistant that allows developers to connect and analyze GitHub repositories. Implemented GitHub OAuth authentication and authorization using Spring Security for secure repository access. Implemented repository indexing and code chunking, converting source code into embeddings and storing them in PostgreSQL with PGVector. Built a RAG pipeline using PGVector similarity search to retrieve relevant code based on user questions. Integrated Spring AI and OpenAI to provide AI-generated answers using the retrieved repository context. The system allows developers to ask questions about their code and receive relevant AI-generated responses. Implemented chat sessions, message persistence, real-time AI response streaming using SSE, and source-code file citations to trace answers back to repository files.

Purpose of the Project

The main purpose of DevPilot is to help developers understand and interact with their GitHub codebases using AI. It uses RAG and vector similarity search to retrieve relevant code from the repository and provides context-aware answers using OpenAI. This reduces the time required to manually search and understand large codebases.

Technologies Used

    Technologies Used
    Java, Spring Boot, Spring Security, Next.js, React, PostgreSQL, PGVector, Spring AI, OpenAI, GitHub OAuth, Docker
